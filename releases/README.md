# Поставки для хостинга

Исправленная редакция приложения — 20261016.6. Архив и отдельный SQL сохраняются в этом каталоге обычным коммитом после базовой проверки.

Сборка выполняется вручную: `python3 tools/package_public_release.py --output output --commit <commit>`. Node.js нужен только для проверки упакованного JavaScript при подготовке поставки; на хостинге он не нужен.

Сначала применяется SQL, затем загружаются все файлы приложения с сохранением частных config.local.php и config.ai.local.php. Недостающие поля старых таблиц добавляет app/lib/schema.php при первом подключении приложения.

Автоматические коммиты и автоматическая публикация релизов через GitHub Actions не используются. Ранние GitHub Releases до редакции 20261016.6 заменены исправленной поставкой из этого каталога.
