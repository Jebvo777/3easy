# EASY3 v6.2 · финальная проверка

Реализация трёх этапов сохранена в GitHub без промежуточных проверок. По указанию владельца финальные проверки начнутся после публикации сборки и публичного установочного архива. Этот документ будет дополнен фактическими результатами.

Изменения касаются главной страницы, окна ожидания AI-подбора и непрерывности контуров изделия. База данных и расчётные алгоритмы не изменяются; обновление с v6.1 не требует SQL.
