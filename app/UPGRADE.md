# Обновление установленного EASY3

1. Сделать обычную резервную копию текущих файлов и БД.
2. Импортировать **только `database/003_upgrade_20261011.sql`** в уже созданную `system404_easy3`. Скрипт добавляет одну таблицу подтверждений производственных затрат. Он не удаляет и не пересоздаёт существующие данные; повторный запуск безопасен.
3. Заменить файлы приложения из нового архива. Сохранить собственный `config.local.php`, если настройки хостинга менялись. В частном архиве настроен исходный целевой хостинг.
4. Перезагрузить вкладку. Если сервер использует свой кеш статических ресурсов, сбросить его. Apache получает правила переоценки JS/CSS.

**Не импортировать `database/install.sql` и `002_seed.sql` для обновления работающей БД.** Они нужны для новой учебной установки. Обновление не подставляет вымышленные затраты в старые предприятия. Факт в существующей компании будет неизвестен, пока собственник не подтвердит затраты принятой части. Кнопка «Открыть демо» создаёт новый изолированный учебный пример с подтверждёнными вымышленными суммами.

Паспорт, цели, маршруты, версии планов, задания, факты и аккаунты остаются на месте. Расстановка и назначения по-прежнему хранятся в JSON существующей компании. Фотографическое HDR-окружение и все ресурсы находятся внутри архива; отдельные зависимости на хостинге не устанавливаются.
