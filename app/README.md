# EASY3 v7.1 · 18 октября 2026

EASY3 связывает цель, план и действие. Швейный пилот работает на PHP 8.2+ и MySQL 5.7+/MariaDB. Composer, Node.js и Python на хостинге не требуются. Полная инструкция обновления — UPGRADE.md.

## Обновление

Сделайте резервную копию. Для перехода с v6.2 замените файлы сайта содержимым установочного ZIP; SQL не требуется. Для более ранних версий сначала импортируйте database/update_20261017_61.sql в текущую system404_easy3. Старые данные и внешние ключи не удаляются. install.sql используется только для новой учебной установки. Конфигурации local имеют приоритет; частная поставка владельца сохраняет его прежние example и local-файлы.

## Сценарии

1. ЦЕЛЬ: ручной заказ или TXT/DOCX/XLSX/XLS/PDF с текстовым слоем. Текст извлекается на сервере, идентификаторы скрываются локально, очищенный текст доступен для проверки. Luna предлагает условия с основаниями; неизвестное остаётся пустым, цель сохраняет человек.
2. ПЛАН: общий портфель → три решения заказа → операции и назначения. Крой разделён на потребность, настилы и передачу. Технология генерируется частями без общего лимита, промышленный пошив отделён от раскроя. Есть перенос узлов/операций, табличный режим, массовая правка, копирование, отмена и проверка времени. Календарь раскрывается в большом окне с днями, неделями и месяцами.
3. ДЕЙСТВИЕ: опубликованные задания, частичный выпуск, передача и ОТК. Принятый объём и история сохраняются.

В прогнозе и симуляции пользователь меняет условия и видит последствия для срока, результата и людей. AI предлагает три стратегии; числа считает общий детерминированный движок. Сценарий сохраняется как снимок и не публикует задания. Использование неподтверждённых оценок AI включается отдельно и даёт условный прогноз. Собственное обучение модели, геометрическая САПР лекал и глобальный оптимум не заявляются. Оптимизация сравнивает варианты общего портфеля и сохраняет выбранный вариант отдельным черновиком.

## Хостинг и файлы

Для AI нужен cURL и исходящий HTTPS к прежнему провайдеру. Основная модель gpt-6-luna, остальные резервные; общий интервал запросов и Retry-After защищают продолжение после RPM/429. Ключи не публикуются в GitHub.

Документы: максимум 12 МБ, извлечённый текст 1,2 МБ, без скрытого обрезания. DOM/XML и zlib нужны для OOXML; mbstring/iconv/zlib для PDF/XLS. Оригиналы и извлечённый текст остаются в закрытом контуре компании. storage/imports должен быть доступен PHP для записи и закрыт от HTTP. Nginx-настройка в tools/nginx.example.conf. Сканированные PDF не распознаются; макросы, формулы и внешние ссылки не запускаются.

Экономика показывает производственный результат в обозначенном охвате, не чистую прибыль компании. Ожидалось, в моменте и прогноз относятся к сопоставимому составу целей. Переключение периода выбирает цели по сроку в календарном дне, неделе или месяце предприятия.
