## Исправление миграции MySQL 5.7

В предоставленном дампе companies/users/orders используют utf8, а прежняя миграция создаёт AI и ПЛАН с utf8mb4 для всех ID. Эта разница нарушает требования внешних ключей и приводит к #1215. Теперь типы и кодировки внешних ID читаются из information_schema.COLUMNS; внешние ключи сохраняются. Для истории ПЛАНА отдельно читается фактический тип plan_workspaces.id. CHECK из миграций удалены. Объединённый скрипт, отдельные миграции и включённые секции install.sql синхронизированы. Существующие таблицы и записи не перекодируются. Импорт на целевом сервере не выполнялся.
