# EASY3 v7 · проверка поставки

Шесть этапов реализации сохранены в GitHub без промежуточных проверок и запуска приложения. По указанию владельца проверки начнутся только после публикации полной сборки и публичного архива. Документ будет дополнен фактическими результатами.

Для обновления с v6.2 отдельный SQL не требуется: используются существующие таблицы и JSON-поля. Приватные конфигурации сохраняются только в частном установочном архиве.
