# Проверки EASY3

Выполнять только на отдельной учебной БД: HTTP-сценарии создают компании, пользователей, планы и факты. Они не очищают чужие данные. Приложению в рабочем хостинге эти зависимости не нужны.

Из корня `app/`:

```sh
php tools/qa/engine_checks.php
python -m pip install requests
python tools/qa/integration.py http://127.0.0.1:8099
cd tools/qa
npm install
cd ../..
node tools/qa/ui_checks.mjs tools/qa/output/state.json
node tools/qa/model_checks.mjs
```

PHP-приложение должно быть запущено отдельно с доступом к установленной тестовой БД. HTTP-проверка создаёт `tools/qa/output/state.json` для DOM-проверки. Этот снимок содержит тестовые имена и адреса; не публиковать его. Второй аргумент HTTP-проверки задаёт каталог результата; UI принимает путь к снимку и необязательный каталог результата, модель — каталог результата.

DOM-harness проверяет действия, формы, переходы и отсутствие WebGL, но не растеризацию, освещение, типографику и реальную работу перетаскивания в браузере. Проверка геометрии проверяет вершины, индексы, UV, замкнутость и реальное изменение геометрии при разрыве. Она не заменяет GPU-проверку изображения.
