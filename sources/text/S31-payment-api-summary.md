# Техническая справка по приложенной документации API

Источник: «Документация по API (3).docx» из архива замечаний. Это описание платёжного API Pally/pal24, а не API генерации Artemox.

Документ охватывает Bearer-авторизацию, счета, платежи, баланс, выплаты, возвраты и postback. Пример создания счёта: `POST /api/v1/bill/create`.

Платёжная интеграция в текущую поставку EASY3 не добавлялась. Для AI используется отдельная инструкция S30 и серверный модуль Artemox.

Публично сохранена техническая сводка. Токены, платёжные реквизиты и примеры персональных данных в неё не включены. Сводка не является актуальной проверкой условий или контрактом платёжного сервиса.
