В репозитории сохраняются **технические редакции**, временные метки, метаданные происхождения и выбранные кадры интерфейса. MP4 и неотредактированные ASR-черновики не опубликованы. Имена замаскированы; личные финансовые и посторонние организационные фрагменты явно обозначены вместо дословного текста.

## Как читать и воспроизводить

[Метод обработки](PROCESSING.md) фиксирует инструменты, версию модели, параметры, отвергнутые пробные способы и ограничения. [Разбор записей](../../docs/RECORDING_REVIEW.md) даёт временные ссылки и последствия для проекта. [Экономический охват](../../docs/ECONOMIC_SCOPE.md) раскрывает важнейшее методическое уточнение.

JSON связывает каждый публичный сегмент с исходными ASR-ID. Неясные слова имеют отметку; личные исключения не выдаются за дословную речь. Для точной формулировки спорного места нужно сверяться с исходным аудио, а не уверенным тоном машинного текста.
