# Большое демо на 23 октября 2026

Исходник — последний прикреплённый дамп (6); прошлое наполнение Q4 ещё не применялось. Генератор `tools/prepare_demo_20261023.py` обрабатывает только локальную расшифровку этого дампа, к серверу не подключается. Дамп и соответствия аккаунтам не публикуются. SQL для конкретного предприятия находится в частной поставке.

Добавляются 24 цели, по 8 на октябрь, ноябрь и декабрь. С тремя прежними целями — 27 целей и 13 230 изделий. Структура: два швейных цеха и отдельная подготовка, 55 участников, 48 ресурсов, 4 бригады. Технологии сборки содержат 432 операции; по подготовке — отдельные сведения и история. Нормы, экономика и новые факты вымышлены. Календари учитывают людей, ресурсы, пятидневку и обед.

Факты добавляются до 22.10.2026 включительно, срез 23.10.2026 00:00 Europe/Moscow. Ноябрь/декабрь остаются будущим планом. В ОТК поло «Команда» — дефект петли: 8 изделий на доработке, 2 ожидают повторной проверки. Стоимость комплектации включается один раз отдельной статьёй. OWN не выдаётся за продажи.

Миграция схемы обязательна, наполнение необязательно. SQL содержит транзакцию, проверку исходной компании/ревизий/числа строк/отпечатков данных и маркер повторного применения. Чужие компании, аккаунты, прежние события и опубликованные планы не переписываются. При изменившейся исходной базе наполнение пропускается. При SQL ошибке импорт останавливается и откатывается.

Ограничения: учебный календарь без праздников и реальных кадровых отсутствий; это демонстрационные нормы, не утверждённый хронометраж предприятия.
