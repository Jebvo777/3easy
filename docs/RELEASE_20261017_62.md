# EASY3 v6.2 · уточнения главной и ожидания AI

Этап 1. На главной убран повторный нижний отступ внутри рабочего стола: место для навигации уже зарезервировано внешним контейнером. Освободившаяся высота передана 3D-петле. Финансовая сводка стала компактнее по высоте и ширине, сохранив три показателя, пояснения и переключатель периода. Стили ограничены главной; окно цели сохраняет крупную финансовую сводку.

По прямому указанию владельца после промежуточных этапов проверки и запуск приложения не выполняются. Сначала публикуются изменения всех этапов, сборка и архив; затем выполняются финальные проверки.

Структура БД и существующие данные не меняются. Для обновления с v6.1 отдельный SQL не требуется.

Этап 2. При запуске и продолжении AI-подбора открывается отдельное окно поверх интерфейса: анимация, три этапа, фактический прогресс, пояснение ожидания и пауза. Обновления меняют только текст и индикаторы, не перезапускают анимацию. Окно закрывается после результата или ошибки; ручное закрытие приостанавливает подбор после текущего шага. Уход из раздела убирает окно и сохраняет возможность продолжить задание.
