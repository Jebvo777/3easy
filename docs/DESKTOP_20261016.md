# Рабочее пространство 16 октября

Рабочий стол сохраняется под окнами: переход на него не создаёт пустой кадр после закрытия планшета. Картина обновляется из последних данных до начала закрытия, старый кадр остаётся до готовности нового. Все три кружка закрывают окно. Нижняя граница визуально продолжается за экран; полезное содержимое укладывается в область над навигацией.

Нижняя панель заменена типографической лентой: пространство, три последовательных контура с номерами, предприятие и паспорт. Активный контур обозначен тонкой линией. Цвета кнопок входа и главной отделены от горного фона; центр крестиков привязан к геометрическому центру кружков.

Фоновый ролик подготовлен из предоставленного 5-секундного материала: конец плавно переходит в начальную часть, аудиодорожка удалена. Видео включается только после входа. До готовности кадра, при блокировке autoplay и при уменьшении движения остаётся изображение. В неавторизованном пространстве видео не запускается.

Промежуточные проверки не выполнялись. Базовая проверка — после публикации всех этапов.
