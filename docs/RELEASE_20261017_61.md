# EASY3 v6.1 · замечания по шести скриншотам 17 октября

Этап 1: фон дополнительно затонирован. Период оформлен крупными кнопками с пояснениями, активным состоянием и диапазоном с годом. Финансовые карточки получили отдельные контрастные стили для тёмного рабочего стола и светлой цели. Убрано дублирование большой прежней суммы над тремя финансовыми фокусами. Стрелка возврата из общего экрана заказа возвращает к портфелю, из внутреннего раздела — к обзору заказа; перед переходом сохраняется черновик.

По прямому указанию владельца проверки и запуск приложения между этапами не выполняются. Сначала публикуются все изменения, сборка и архив, затем итоговые проверки.
