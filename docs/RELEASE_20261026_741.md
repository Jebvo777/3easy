# EASY3 7.4.1 — оформление трёх способов пошива

Основание: замечание владельца и скриншот от 26 октября 2026 года. База — окончательная поставка 7.4, коммит aecc3288151ba3a9eb88a48cfc5c6838ce3f4b6f.

1. Исправлена общая компоновка «Целое изделие», «По узлам» и «Поток»: схема получает минимальную рабочую высоту, нижние разделы не сжимают её до полосы.
2. Карта и боковой инспектор находятся в одной строке на компьютере; на узком экране инспектор расположен под картой. Прокрутка карты и свойств остаётся внутри их границ.
3. Параметры плана собраны в компактный раскрываемый блок. Объём, передаточная пачка и сменная потребность доступны с прежней логикой.
4. «Задание на смену» свёрнуто при входе. Дата и рассчитанное количество видны в заголовке, таблица и показатели открываются по нажатию.
5. Прогноз заработка перенесён внутрь прокручиваемого содержимого плана: он не создаёт дополнительный блок за границей окна.
6. Состояние раскрытых разделов сохраняется при редактировании текущего плана и переключении способа пошива.
7. Обновлены готовые JS/CSS и версия ресурсов для загрузки нового оформления браузером.

## Установка поверх 7.4

Загрузить содержимое EASY3_741_overlay.zip поверх сайта без удаления каталога. index.php расположен в корне архива. Действующие config.local.php, config.ai.local.php, config.example.php и config.ai.example.php исключены из поставки; пользовательское содержимое storage не включено. Не удалять серверные конфигурации и storage. После загрузки обновить страницу Ctrl+F5.

Новая миграция БД не требуется. Для сайта, уже обновлённого до 7.4, повторно импортировать SQL не нужно.

Проверки, тесты, линтеры и запуск приложения не выполнялись по прямому указанию владельца. Выполнены только правки исходников, сборка статических ресурсов и упаковка. Визуальная приёмка развёрнутого сайта не заявляется.
