# Генерация технологии по узлам

Поставка 16 октября отменяет общий лимит 50 операций. Artemox и серверная конфигурация ключа сохраняются. Сначала AI формирует узлы изделия с зависимостями; затем по каждому узлу выдаёт целые страницы неделимых операций до has_more=false. Размер страницы служит только транспортным ограничением ответа, а не пределом технологии. Прогресс сохраняется в БД. Окно можно закрыть и продолжить; ошибка части не стирает готовые узлы.

Внешний контекст содержит только техническое описание, названия узлов и подобранные технические записи справочника. Компания, заказчик, имена, цены и производственная история не передаются. Справочник: 6514 операций и 6979 вариантов из предоставленной номенклатуры. Условия и источник варианта видны в редакторе. Найденное время остаётся оценкой; нормы подтверждает человек.

Структура: изделие → node_id/node_name → операции со стабильными id, зависимостями, типом, оборудованием, разрядом и примечанием. Ручной редактор добавляет, копирует и удаляет операции, меняет узлы, связи и время; образцы — независимые копии. Числовые оценки не являются доказанным нормативом.

API: technology_generate создаёт задачу; technology_step выполняет одну часть; technology_status и technology_jobs восстанавливают состояние. Сервер проверяет роль, компанию, ревизию заказа и CSRF. Внешний вызов идёт без блокировки БД и PHP-сессии. Аренда запроса исключает одновременную генерацию одной части; не гарантирует поведение оплаты внешнего провайдера при транспортном обрыве.

Исходники и редактор опубликованы до базовой проверки по заданию владельца. Для запуска требуется update_20261016.sql и частный config.ai.local.php; ключ не входит в GitHub.
