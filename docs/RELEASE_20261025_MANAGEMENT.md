# EASY3 7.3.2 · руководство в нескольких подразделениях

Прямое уточнение владельца: раздел «Команда» не пропал. В карточке руководства нужен одновременный выбор нескольких подразделений. Поставка поверх сайта; SQL только при необходимости. Прежний запрет проверок и субагентов сохраняется.

## Изменения

Команда → Руководство: подразделения выбираются флажками, есть «Выбрать все». Нужно выбрать хотя бы одно; повторное редактирование сохраняет весь набор. Список показан под именем руководителя и на схеме. Начальник производства, технолог и бригадир поддерживают несколько подразделений, включая совмещение руководящих ролей.

В схеме один руководитель может относиться к нескольким колонкам. Повторные визуальные карточки имеют уникальные идентификаторы и открывают одну общую запись сотрудника. Связи начальников/технологов учитывают выбранные подразделения. Карточка человека в структуре компании позволяет открыть каждое из его подразделений.

У бригады остаётся одно подразделение; оно должно входить в набор подразделений бригадира. При создании бригады можно выбрать одно из отмеченных подразделений. Снять подразделение действующей бригады до её переназначения нельзя. Исполнители и оборудование сохраняют одно физическое подразделение. Смена ответственных подразделений руководителя не переносит оборудование и производственные факты.

## Данные и установка

Новый массив workshops в записи руководителя хранится в существующем JSON-паспорте companies.passport. Поле workshop сохранено как основное для совместимости. Старое одиночное назначение читается как набор из одного подразделения; сервер проверяет полный набор и принадлежность бригады. Новые таблицы, поля, SQL и изменение кодировки MySQL 5.7 не требуются. Опубликованные снимки не переписываются.

Архив содержит все файлы приложения и собранные JS/CSS для загрузки поверх. Файлы конфигурации не заменяются; папка storage и существующая база сохраняются. После загрузки обновить страницу Ctrl+F5 и сохранить руководителя в Команда → Руководство. Если требуется прежняя миграция QR/демо 7.3.1, она сохранена отдельно в database/update_20261025_qr_demo.sql; к множественному выбору она не относится.

Сборка выполнена. Проверки, тесты, линтеры и запуск приложения не выполнялись по прежнему указанию владельца.
